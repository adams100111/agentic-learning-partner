# Content Adaptation Policy

## Separate proposal causes

ALP distinguishes three causal categories:

### Learner adaptation

Triggered by learner evidence.

Examples:

- change analogy;
- add targeted exercise;
- reinforce a misconception;
- adjust depth.

### Technical freshness

Triggered by authoritative source change or stale verification.

Examples:

- deprecated API;
- changed framework recommendation;
- security guidance update;
- new language/runtime behavior.

### Curriculum design

Triggered by coverage/structure analysis.

Examples:

- competency not covered;
- duplicated material;
- lesson scope too broad;
- prerequisite ordering problem.

These categories must not collapse into one generic "rewrite content" reason.

## Immediate vs checkpoint changes

Immediate/session-local:

- hints;
- next exercise;
- analogy choice;
- review queue;
- session plan.

Checkpoint/batched durable content changes:

- lesson prose;
- permanent new exercise;
- lesson split/merge;
- curriculum structure.

This prevents one bad session from thrashing durable course content.
