# Learning Plan

## Ownership

The learner-specific learning plan belongs to the learner workspace as a derived/materialized view.

It is distinct from:

- domain taxonomy;
- platform curriculum;
- platform progression constraints.

## Relationship

```
Domain competency taxonomy
          |
Platform curriculum/content
          |
Learner evidence + assessments
          |
ALP learner-specific learning plan
```

## Consumption modes

ALP may recommend one of:

- `skip`;
- `skim`;
- `challenge-only`;
- `full`.

The platform may still enforce its own unlock/progression rules.

When platform constraints conflict with the learning recommendation, ALP should surface the mismatch rather than treating the constraint as pedagogical truth.
