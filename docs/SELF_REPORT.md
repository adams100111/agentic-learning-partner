# Learner Self-Report

## Role

Self-report is valid evidence but is weaker than demonstrated behavior for competency claims.

It may strongly influence:

- diagnostic depth;
- question selection;
- persona/preferences;
- learning-plan sequencing.

## Competency limits

Self-report alone must not establish high domain-specific competence such as `strong` or `production-ready` where ALP has no supporting demonstrated evidence.

Example:

"I know PostgreSQL very well"

may justify skipping generic SQL explanation, but does not automatically establish:

```
go.database.pooling = strong
```

Shared competencies and domain implementation competencies remain distinct.
