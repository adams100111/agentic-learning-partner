# Assessment Acceptance Policy

## Goal

Avoid both extremes:

- asking the learner to approve every minor assessment;
- allowing agents to silently promote important competencies without sufficient safeguards.

## Default policy

Use risk-based acceptance.

### Ordinary learning evidence

Examples:

- diagnostic activity;
- exercise;
- code-reading task;
- routine project checkpoint.

Agent assessment may be accepted automatically when:

- the rubric/version is valid;
- required evidence references exist;
- no hard-gate rule is violated;
- confidence is not obviously contradictory to existing state.

### Hard-gated promotions

Promotions to `production-ready` require the domain rubric's hard evidence criteria.

No agent may bypass these gates merely by increasing confidence.

### Contradiction handling

A materially contradictory new assessment should:

1. be persisted;
2. lower confidence or flag reassessment according to projection policy;
3. not silently delete prior assessment history.

### Persona changes

Explicit learner corrections may apply immediately with provenance and a concise change summary.

Agent-inferred or wizard-synthesized durable persona changes require confirmation when materially consequential.

## Principle

Automate routine state maintenance; require stronger safeguards as consequence/reversibility rises.
