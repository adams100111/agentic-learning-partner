# Domain Pack Overrides

## Learner/workspace overrides

Workspace configuration may override teaching preferences for a domain.

Examples:

- project-first preference;
- analogy preference;
- activity format;
- pacing.

## Not workspace-overridable by default

Learner state must not casually redefine:

- competency taxonomy;
- hard production-ready criteria;
- security gates;
- migration rules;
- source authority rules.

Changes to those belong in the domain pack itself through normal engine/domain-pack development.

## Rationale

Teaching personalization and competency truth are different concerns.
