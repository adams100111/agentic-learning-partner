# Domain Documentation

ALP uses a single domain-documentation context.

- Canonical vocabulary: `/GLOSSARY.md`
- Architectural decisions: `/docs/adr/`
- Product/architecture/state policies: `/docs/`
- Executable structural contracts: `/schemas/`
- Domain-pack references: `/domains/`

Agents must use glossary vocabulary and respect accepted ADRs in the area they modify.

Do not duplicate ADR or architecture content into tickets; point to the canonical document instead.
