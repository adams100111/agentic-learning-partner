# Review Learning Progress

Use this for periodic progress review or when the learner asks what ALP currently believes.

## Workflow

1. Use `alp status` for the current projection.
2. Use `alp competency show <id>` for any competency that needs explanation.
3. Distinguish level from freshness/confidence.
4. Prioritize review by risk, evidence strength, prior failures, dependency importance, and current project relevance.
5. Count real recent project use as review evidence when it genuinely exercises the competency.
6. Recommend reassessment only where current evidence is stale, contradictory, or insufficient for the next decision.
7. Avoid re-running broad diagnostics when targeted evidence will answer the question.

Read `docs/REVIEW_AND_DECAY.md` when scheduling rationale is needed.
